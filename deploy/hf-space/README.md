# FileBeam — live public demo

Drop a file → get a 6-character code + link + QR → anyone opens it in any browser to download. Files self-destruct in 60 minutes.

This is the official hosted instance of [FileBeam](https://github.com/Kawshikmr/filebeam) — single-file Python, zero accounts, zero installs.

**Demo limits:** 1 GB per beam · 60-minute expiry · nothing stored long-term.
