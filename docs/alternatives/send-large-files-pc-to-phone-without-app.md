# How to Send Large Files from PC to Phone Without Any App

Sending a 2 GB to 10 GB video, backup, or dataset from a Windows PC to an iPhone or Android phone without cables or iTunes:

## The Zero-App Method using FileBeam

1. Open terminal and run:
   `ash
   curl -sSL https://filebeam.dpdns.org/run | python3
   `
2. Drop your large file into the browser window that opens.
3. Scan the generated QR code with your phone camera.
4. The file downloads directly over your local Wi-Fi in seconds without using mobile data.

Source code and documentation: [Kawshikmr/filebeam](https://github.com/Kawshikmr/filebeam)
